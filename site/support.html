Beseda support

Beseda is a menu bar app for Apple Silicon Macs running macOS 14.2 or newer. An internet connection is needed to download models. The direct build may also download its summary engine and app updates; Apple handles Store app updates. Transcription with an installed speech model runs locally.

First launch and speech model

Look for Beseda’s icon in the menu bar. In the first-run window, allow microphone and system-audio access, choose a speech model, and select Download. Parakeet v3 supports 25 languages; GigaAM v3 is for Russian. You can change the model later in Settings → Processing. Recording cannot start until the selected speech model is ready.

Allow at least 1 GB of free disk space for transcription only, or 6 GB if you also want the built-in summary model. If a download reports insufficient space, free space and try again. Model downloads need an internet connection; the app shows download progress in the menu bar.

Permissions and recording

If a source is missing, check macOS System Settings → Privacy & Security for Beseda’s microphone and system-audio permissions. In Beseda, use Settings → Recording → Check Sound to test both channels without saving a call. Start or stop a recording from the menu bar. Automatic recording only applies to apps selected under Settings → Recording → Apps.

You are responsible for recording lawfully and obtaining participants’ consent. Beseda does not notify other participants for you.

Local and cloud summaries

Recording and transcription do not require a summary provider. In Settings → Processing, choose the built-in Gemma model for summaries on this Mac (a separate download), OpenRouter with your own key, or LM Studio. A remote LM Studio server or OpenRouter can receive call text. Optional classification, live key points and webhooks can also send text outside the Mac. Check the provider note in Settings → Processing and the privacy page before enabling them. “Local only” uses the built-in model for summaries and live key points and turns off Jev classification and webhooks.
