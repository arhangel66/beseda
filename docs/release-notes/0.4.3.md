# Beseda 0.4.3

Нужен macOS 14.2 или новее.

## Исправления

- Голос из AirPods снова записывается: когда программа звонка переключает наушники в режим гарнитуры, Беседа продолжает запись микрофона, а не теряет его до конца звонка.
- «Расшифровать снова» работает и для звонка с пустым микрофоном: расшифровывается сторона собеседников.
