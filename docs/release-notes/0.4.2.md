# Beseda 0.4.2

Нужен macOS 14.2 или новее.

## Исправления

- Запись больше не останавливается, пока вы ждёте собеседника: минута тишины считается, только когда его уже было слышно, а до этого запись ждёт до 15 минут.
- Автозапись не обрывается, если программа звонка на мгновение отпустила микрофон, например когда к звонку подключается собеседник.
