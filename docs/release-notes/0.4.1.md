# Beseda 0.4.1

Нужен macOS 14.2 или новее.

## Что нового

- Приложение подписано и проверено Apple: macOS больше не предупреждает о неизвестном разработчике.
- Говорящих можно назвать по имени, у каждого свой цвет; собеседники в звонках на несколько человек различаются надёжнее, старые звонки переразбиваются в фоне.
- Интерфейс на английском, если macOS настроена на английский.
- Понятнее, когда не удаётся связать звонок с календарём, и исправлен запрос доступа к календарю.
- Настройка «Сразу» для аудио удаляет его сразу после расшифровки.
- Записи, перенесённые из Подушки, снова находят своё аудио: работают прослушивание и повторная расшифровка.

## Исправления

- Звонок мог не сохраниться с ошибкой `no such table: call_speaker_merges`.
- Ложное предупреждение, что речевая модель не скачана.

После обновления macOS может один раз спросить доступ к Связке ключей: нажмите «Разрешить всегда».
