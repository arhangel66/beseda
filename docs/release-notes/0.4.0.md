# Beseda 0.4.0

Нужен macOS 14.2 или новее.

## Что нового

- Запись сразу пишется на диск: звонок не теряется, если приложение закрылось или упало посреди разговора.
- Реже путаются говорящие: фразы собеседников и ваши надёжнее разделяются по голосам.
- Типы звонков: вы описываете свои виды встреч со своими подсказками, а Jev (или модель итогов) сам определяет тип звонка и пишет итог под него.
- Экспорт итогов в Markdown: каждый итог с расшифровкой сохраняется в выбранную папку.
- Блок «В прошлый раз»: на экране звонка и у предстоящей встречи в календаре — решения, следующие шаги и открытые вопросы прошлого связанного звонка.
- Можно включить расшифровку прямо во время звонка.
- Переключатель «Только локально»: ничего не уходит с Mac, итоги пишет встроенная модель.
- Ключи API хранятся в Связке ключей macOS, а не в файле настроек.
- Исправлены падения и случаи, когда пропадала часть записи.
